# 프렛 코치 (Fret Coach) 🎸

기타 타브 악보를 보면 "몇 번 줄 몇 프렛"만 나오고 **어떤 손가락으로 눌러야 하는지** 알 수 없어서
유튜브 영상을 봐야 했던 문제를 풀기 위한 개인 연습용 웹앱입니다.

- 주소: https://beck-akajk.github.io/fretboard-coach/
- 모바일 우선(세로 화면)으로 만들었고, 폰 브라우저에서 바로 열어 쓸 수 있습니다.

## 무엇을 해 주나

1. **.gp3 / .gp4 / .gp5 파일을 브라우저에서 바로 읽습니다.**
   파일을 열거나 화면에 끌어다 놓으면 트랙·튜닝·마디·음(줄/프렛/길이)을 즉시 파싱합니다.
   파일은 서버로 전송되지 않고, 한 번 연 파일은 이 브라우저(IndexedDB)에 저장되어 다음에 바로 꺼내 쓸 수 있습니다.

2. **코드 폼 기반 운지 (아르페지오)**
   마디(또는 반 마디)에 등장하는 음들을 오픈/바레/파워 코드 폼과 대조해 **기준 코드 폼**을 고르고,
   폼 안의 음은 폼의 손가락으로, 폼을 벗어난 음은 남는 손가락(주로 4번)으로 배정합니다.
   - 화면 위 **`기준 코드 폼` 카드에 그 코드의 운지를 그린 미니 코드표(SVG)**가 함께 나옵니다.
     지판·타브와 같은 가로 방향(왼쪽이 낮은 프렛, 위가 1번줄, `줄 순서 ⇅` 토글 반영)이라 눈을 옮기지 않아도 됩니다.
     뮤트(×)·개방(○)·시작 프렛(2fr·3fr …)·손가락 번호별 색 점, 1번 손가락 바레 세로 막대까지 한눈에 보입니다.
   - 1번 손가락이 바레로 누르고 있는 프렛의 음(예: A폼 D `x57775`에서 2번줄 5프렛)은 폼 밖 음이 아니라
     **1번 검지 바레로 소리 나는 음**으로 표시합니다(파란 1번 배지가 바레 막대 위에 찍힘).
   - 지판은 **1~12프렛이 항상 같은 자리에 고정**으로 보입니다(3·5·7·9·12프렛 인레이 점도 고정). 12프렛을 넘는 음이 나오는 마디에서만 그 음이 들어오도록 프렛 범위를 넓힙니다.
   - 지판에는 지금 누르는 음을 쨍한 색 배지로, **유지하면 좋은 기준 폼 손가락은 손끝 마디·몸통이 있는 흐릿한 손가락 실루엣**으로 깔아 둡니다.
   - **이번 마디 미리보기**: 지금 마디에 등장하는 모든 음이 지판에 함께 보입니다.
     지금 음은 진한 배지+글로우, 같은 마디에서 곧 칠 음은 **점선 테두리의 흐린 표시**(손가락 번호 작게), 이미 지난 음은 한 단계 더 흐린 점으로 남아
     손가락이 어디로 갈지 지판만 보고 준비할 수 있습니다. 폼 밖 음(예: 1번줄 5프렛·개방현)도 마디에 나오면 흐리게 함께 보입니다.
     같은 줄·프렛에는 하나만 그립니다 — 우선순위 `현재 음 > 유지 폼 > 다가올 음 > 지나간 음`.
     같은 줄을 다른 프렛으로 치는 순간에도 폼의 손가락은 아주 연하게 남겨, 네 손가락 모양이 끊기지 않습니다.
   - 바레 폼에서는 1번 손가락이 여러 줄을 이어 누르는 모양을 **세로 반투명 막대**로 이어 그립니다.

3. **곡별 튜닝 표시 · 튜닝 연동 코드 판별**
   곡 정보 바로 아래(폰 한 화면에서 바로 보이는 자리)에 현재 트랙의 튜닝 배지가 뜹니다.
   `Standard · E A D G B E`, `Drop C · C G C F A D` 처럼 6번줄→1번줄 개방현 음을 함께 보여 주고, 카포가 있으면 `카포 2`를 덧붙입니다.
   기본 튜닝이 아니면 배지가 주황색으로 살짝 강조되고 `줄 다시 맞추기`가 붙어, 기타 줄을 다시 맞춰야 한다는 걸 바로 알 수 있습니다.
   Standard · Half-Step Down(E♭) · D Standard · Drop D · Drop C# · Drop C · Drop B · C#/C/B Standard · Open G/D/E/C · DADGAD ·
   Drop A · 7현 · 베이스 표준을 알아보고, 목록에 없으면 `커스텀 튜닝`으로 표시합니다.
   지판 왼쪽 줄 이름(`1·E ~ 6·E`)도 같은 튜닝을 쓰고, 반음 내림 튜닝은 `E♭ A♭ D♭ G♭ B♭ E♭`처럼 플랫으로 표기합니다.
   코드 폼 엔진도 고정 표준 튜닝 대신 트랙 튜닝을 받아 계산합니다 — 폼을 근음 대비 음정 템플릿으로 바꿔 각 줄의 실제 음에 맞게 프렛을 다시 계산하므로,
   Drop D 개방 6·5·4번줄은 `D5`, Drop C에서는 `C5`로 잡히고 코드명도 그 튜닝에서 실제로 울리는 화음과 일치합니다. 표준 튜닝 곡은 기존 폼을 그대로 씁니다.

4. **포지션 기반 운지 (솔로/리프)**
   이벤트 단위 DP로 손 위치(1번 손가락 기준 프렛)를 정하고, 이동 비용과 손가락 전환 비용을 최소화해
   1~4번 손가락을 배정합니다. 4프렛 박스가 지판에 표시됩니다.
   포지션 모드에서도 그 마디에 판별되는 코드가 있으면 `기준 코드 폼` 카드에 **코드명과 미니 코드표**를 함께 보여 줍니다(운지는 포지션 그대로, 카드만 참고용).

5. **연습 도구**
   - Web Audio 클린 기타 톤(Karplus-Strong) 재생, 속도 **0.2x~1.0x**(슬라이더 + `0.2×·0.25×·0.35×·0.5×·0.75×·1×` 빠른 선택 칩).
     속도는 음 길이·메트로놈 간격·커서 진행에 모두 같은 값으로 적용되고, 재생 중에 바꾸면 그 자리에서 새 속도로 이어집니다.
   - 이전/다음 음·마디 이동, 타브 클릭으로 그 음으로 점프
   - 구간 반복 `시작(A)` / `끝(B)` / `해제`, 메트로놈
   - 지판 줄 순서 전환(6번줄 아래 ↔ 1번줄 아래)
   - 하단 타브는 1~6번줄 여섯 줄이 모두 여유 있게 보입니다(줄 눈금을 SVG로 그리고, 위·아래 음이 잘리지 않도록 줄 간격·여백을 잡았습니다)

6. **내 악보 보관함 (구글 드라이브 동기화)**
   화면 맨 위 `내 악보 보관함` 패널이 앱을 열 때마다 내 구글 드라이브의 **`프렛 코치` 폴더**를 바로 불러옵니다.
   별도 로그인·설정 없이 폰과 노트북 어디서 열어도 같은 목록이 뜨고, 항목마다 파일명·용량·날짜와 `열기`·`삭제`가 있습니다.
   - `📂 .gp 파일`로 연 곡은 화면에 바로 열리면서 **백그라운드로 드라이브에 자동 저장**됩니다(앞의 `저장 중… → 저장 완료` 안내).
   - 목록에서 `열기`를 누르면 드라이브에서 받은 원본 바이트를 그대로 파싱해 열고, 그 곡이 `지금 보는 중`으로 강조됩니다.
   - `삭제`는 확인 후 드라이브 휴지통으로 보냅니다(모든 기기 목록에서 사라짐).
   - 드라이브에 연결하지 못해도 앱은 그대로 동작합니다 — 이 기기에 저장된 곡과 내장 데모로 계속 연습할 수 있습니다.
   - 연결 백엔드는 구글 Apps Script 웹 앱(구글 드라이브 `프렛 코치` 폴더의 목록·받기·올리기·삭제)이며, 주소는 `js/drive.js`의 `API` 상수에 들어 있습니다. 서비스 워커는 이 주소를 캐시하지 않고 항상 네트워크로 보냅니다.

## 데모

기본 내장 데모는 **직접 만든 진행(D – Bm7 – G – A 아르페지오 + 솔로 리프)** 입니다.
저작권 있는 원곡 악보는 저장소에 넣지 않습니다. 악보는 사용자가 직접 올려서 씁니다.

## 폰에서 쓰기

1. 폰 브라우저(크롬)로 https://beck-akajk.github.io/fretboard-coach/ 열기
2. 메뉴 → **홈 화면에 추가** (PWA 매니페스트·서비스 워커가 들어 있어 앱처럼 열리고, 한 번 연 뒤에는 오프라인에서도 열립니다)
3. 한 번 올린 .gp 파일은 기기 브라우저 저장소(IndexedDB)에 남아 다음에 칩으로 바로 불러올 수 있습니다.

> 나중에 APK로 만들 때는 `소이의하루`처럼 이 URL을 WebView로 감싸면 됩니다(별도 서버·로그인 없음).

## 개발 메모

- 빌드 없음. `index.html` + `css/` + `js/` + `vendor/`(alphaTab) 그대로 정적 호스팅.
- `mobile.html` — 데스크톱에서 390×844 폰 화면으로 확인하는 보조 페이지.
- 파일을 고친 뒤에는 `index.html`의 `?v=` 값을 올려 캐시를 갱신하세요(지금은 `20261122t`, `sw.js` 캐시는 `fretcoach-v8`).
- 보관함 연동은 `js/drive.js` — Apps Script API 호출(`list`·`get`·`upload`·`delete`), Base64 변환, 목록 패널 렌더링이 모두 여기 있습니다.
- 운지 엔진: `js/chords.js`(코드 폼 사전·매칭 점수), `js/finger.js`(구간 분할·손가락 배정·포지션 DP), `js/score.js`(GP 파싱 정규화).
- 코드표 그림과 지판의 흐릿한 손가락·바레 막대는 `js/app.js`의 `chordDiagramSVG()` / `barreGroups()` / `ghostBody()`·`ghostTip()`에서 그립니다.
  마디 미리보기는 `drawFretboard()` 앞부분에서 마디 이벤트의 음을 모아 `previewMark()`로 그리고, 하단 타브의 6줄 눈금·음 위치는 `TAB_ROW`(top·gap·height) 한 곳에서 맞춥니다.
  같은 손가락이 같은 프렛으로 두 줄 이상을 짚으면 자동으로 바레 막대로 묶습니다.
- 바레 판정은 `js/chords.js`의 `barreOfShape()`·`isBarreNote()`가 합니다(바레 프렛 위의 음은 `kind:'barre'`, 1번 손가락).
  폼 손가락 고스트는 `ghostsForShape()`가 "줄+프렛" 단위로 남기고, 같은 줄을 다른 프렛으로 칠 때는 `faint:true`가 됩니다.
- 운지 엔진 회귀 확인: `test/engine_check.py`(quickjs 필요, 저장소에는 올리지 않음).

## 참고

- 악보 파일은 브라우저 안에서만 읽고, 연 곡은 이 기기 브라우저(IndexedDB)에 남습니다.
- 다른 기기에서도 같은 곡을 쓰려면 `내 악보 보관함`에 올려 두세요 — 드라이브 `프렛 코치` 폴더를 통해 어느 기기에서나 열립니다.
